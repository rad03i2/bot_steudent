## ✨ المزايا (المرحلة الأولى)

- **مجاني بالكامل**: الرسائل تُفهم بمحلّل عربي محلي (`study_bot/rules.py`) يعمل على جهازك، بدون إرسال رسائلكم لأي جهة خارجية وبدون أي تكلفة.
- **يفهم اللهجات**: "باجر"، "بكرة"، "الخميس الجاي"، "الخميس اللي بعده"، "بعد أسبوعين"، "26/11"، "10 كانون الثاني"، "الساعة 2"، "الساعة 9 الصبح".
- **تواريخ دقيقة**: التاريخ يُحسب بالكود (`study_bot/dates.py`)، فلا يخطئ في الأيام.
- **يتعلم أسماء المواد**: بعد أول مرة تُذكر فيها المادة، يتعرف عليها بأي صيغة ("الفيزياء"، "بالفيزياء"، "للفيزياء").
- **التعديل بالرد**: اعمل Reply على بطاقة الموعد واكتب "تأجل للخميس"، فيعرف البوت أي موعد تقصد.
- **إضافة وتعديل وحذف**: "كويز الكيمياء تأجل للأحد"، "انلغى واجب الإحصاء".
- **بدون تكرار**: إذا ذكر طالبان الموعد نفسه، يُسجَّل مرة واحدة ويُكتب "✅ مؤكد من طالبين".
- **كشف التعارض**: إذا قال طالب الخميس وآخر الأربعاء، ينبّه البوت القروب.
- **جداول مرتبة** حسب اليوم والأولوية (فاينل ← ميد ← امتحان ← كويز/مشروع ← واجب)، مع تمييز الأيام الثقيلة.
- **أوامر سريعة** تعمل حتى بدون ذكاء اصطناعي.

| الأمر | الوظيفة |
|---|---|
| `/today` | جدول اليوم |
| `/tomorrow` | جدول الغد |
| `/week` | بقية هذا الأسبوع |
| `/nextweek` | الأسبوع القادم |
| `/upcoming` | كل المهام في الـ 30 يوماً القادمة |
| `/exams` | الامتحانات القادمة |
| `/chatid` | رقم المحادثة (لضبط `ALLOWED_CHAT_IDS`) |
| `/help` | طريقة الاستخدام |

## 🚀 التشغيل

### 1. أنشئ البوت في تيليجرام
1. افتح [@BotFather](https://t.me/BotFather) واكتب `/newbot` واتبع الخطوات، وانسخ **التوكن**.
2. **مهم جداً:** اكتب لـ BotFather الأمر `/setprivacy` واختر البوت ثم **Disable**.
   بدون هذه الخطوة لن يرى البوت رسائل القروب العادية.
3. أضف البوت إلى قروب الدفعة.

### 2. شغّل البوت

```bash
git clone https://github.com/rad03i2/bot_steudent.git
cd bot_steudent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ثم ضع التوكن داخل .env
python -m study_bot
```

بس هذا. لا تحتاج أي مفتاح آخر.

أو باستخدام Docker:

```bash
docker build -t study-bot .
docker run -d --name study-bot --env-file .env -v study-bot-data:/data --restart unless-stopped study-bot
```

### 3. (اختياري) اقفل البوت على قروبكم
اكتب `/chatid` داخل القروب، وضع الرقم في `ALLOWED_CHAT_IDS` داخل `.env` ثم أعد تشغيل البوت.
بعدها لن يستجيب البوت إلا لهذا القروب، ولأعضائه على الخاص.

## ⚙️ الإعدادات

كل الإعدادات في `.env` (انظر `.env.example`):

| المتغير | الافتراضي | الشرح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | توكن البوت (إلزامي، مجاني) |
| `ANTHROPIC_API_KEY` | فارغ | اختياري ومدفوع: إذا وُضع يستخدم Claude بدل المحلّل المجاني |
| `CLAUDE_MODEL` | `claude-opus-5-5` | النموذج المستخدم |
| `CLAUDE_EFFORT` | `low` | عمق التفكير (low / medium / high) |
| `TIMEZONE` | `Asia/Baghdad` | المنطقة الزمنية |
| `WEEK_START` | `sunday` | أول يوم في الأسبوع |
| `MONTH_STYLE` | `levantine` | `levantine` = تشرين الثاني، `standard` = نوفمبر |
| `DB_PATH` | `data/study_bot.db` | مكان قاعدة البيانات |
| `ALLOWED_CHAT_IDS` | فارغ | القروبات المسموحة |
| `GROUP_PREFILTER` | `true` | في القروب، يحلّل فقط الرسائل التي فيها كلمات دراسية |

## 🆓 أين أشغّل البوت مجاناً؟

البوت يحتاج جهازاً يبقى شغالاً حتى يرد على الرسائل. GitHub يحفظ الكود فقط ولا يشغّل البوت.
الخيارات المجانية:

1. **حاسبتك الشخصية**: الأسهل للتجربة، لكن البوت يتوقف عندما تطفئها.
2. **سيرفر Oracle Cloud المجاني (Always Free)**: سيرفر صغير مجاني دائماً ويكفي البوت بسهولة.
   التسجيل يطلب بطاقة بنكية للتحقق فقط. بعد إنشاء السيرفر (Ubuntu)، نفّذ خطوات "شغّل البوت" أعلاه،
   ثم اجعله يعمل دائماً بـ Docker (الأمر في الأعلى مع `--restart unless-stopped`).
3. **أي جهاز قديم في البيت يبقى شغالاً** (لابتوب قديم أو Raspberry Pi) بنفس خطوات التشغيل.

قاعدة البيانات ملف واحد صغير (`data/study_bot.db`). خذ منه نسخة احتياطية من فترة لفترة.

## 🤖 (اختياري ومدفوع) فهم أذكى عبر Claude

المحلّل المجاني يفهم أغلب الصيغ الشائعة، لكنه يعتمد على قوائم كلمات.
إذا احتجتم فهماً أذكى للجمل المعقدة مستقبلاً:

```bash
pip install -r requirements-ai.txt
```

ثم ضع `ANTHROPIC_API_KEY` في `.env`. هذا الخيار مدفوع حسب الاستخدام، ويمكن إلغاؤه بحذف المفتاح.

## 🧱 بنية المشروع

```
study_bot/
├── __main__.py      # نقطة التشغيل
├── config.py        # الإعدادات
├── arabic.py        # تطبيع النص العربي، أسماء الأيام والأشهر
├── dates.py         # تحويل "الخميس الجاي" إلى تاريخ (حتمي)
├── rules.py         # المحلّل العربي المجاني (الافتراضي)
├── llm.py           # (اختياري) فهم الرسائل عبر Claude
├── db.py            # التخزين في SQLite
├── formatting.py    # تنسيق البطاقات والجداول
├── service.py       # المنطق الأساسي (مستقل عن تيليجرام)
└── telegram_bot.py  # ربط المنطق بتيليجرام
tests/               # اختبارات (pytest)
```

تشغيل الاختبارات:

```bash
pip install -r requirements-dev.txt
pytest -q
```
