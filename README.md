# 📚 مُذكِّر الدفعة

بوت تيليجرام لطلاب الدفعة: يقرأ رسائل القروب، ويفهم أي موعد دراسي ينذكر (امتحان، كويز، ميد، فاينل، واجب، مشروع، تقرير...)، ويحسب تاريخه بدقة، ويرتب كل شيء في جداول أنيقة حسب الأيام والأسابيع.

```
طالب: الخميس الجاي امتحان فيزياء الفصل الثالث والرابع

البوت:
📝 تمت إضافة امتحان جديد إلى الجدول
━━━━━━━━━━━━━━━━━━
📘 المادة: فيزياء
📝 النوع: امتحان
📅 الموعد: الخميس 26 تشرين الثاني 2026
📖 المحتوى: الفصل 3 و 4
⏳ باقي 6 أيام
👤 أضافه: أحمد
[✅ صحيح، أأكّد]  [🗑 حذف]
```

```
طالب: شنو عدنا الأسبوع الجاي؟

البوت:
🗓 جدول الأسبوع القادم
   22 – 28 تشرين الثاني 2026
━━━━━━━━━━━━━━━━━━

🔹 الأحد 22/11 (بعد غد)
   📘 واجب رياضيات – تمارين 4.1 إلى 4.5

🔹 الثلاثاء 24/11
   📄 تقرير كيمياء – التجربة 5

🔴 الخميس 26/11  ← يوم ثقيل! 💪
   📝 امتحان فيزياء – الفصل 3 و 4
   📊 مشروع برمجة – المرحلة الأولى

━━━━━━━━━━━━━━━━━━
📌 المجموع: 4 مهام
🔥 الأهم: امتحان فيزياء (باقي 6 أيام)
```

## ✨ المزايا (المرحلة الأولى)

- **فهم اللغة الطبيعية** بكل اللهجات: "باجر"، "الخميس الجاي"، "بعد أسبوعين"، "26/11"، "10 كانون الثاني".
- **تواريخ دقيقة**: الذكاء الاصطناعي يفهم المعنى، والكود يحسب التاريخ (`study_bot/dates.py`)، فلا يخطئ في الأيام.
- **إضافة وتعديل وحذف**: "كويز الكيمياء تأجل للأحد"، "انلغى واجب الإحصاء".
- **بدون تكرار**: إذا ذكر طالبان الموعد نفسه، يُسجَّل مرة واحدة ويُكتب "✅ مؤكد من طالبين".
- **كشف التعارض**: إذا قال طالب الخميس وآخر الأربعاء، ينبّه البوت القروب.
- **جداول مرتبة** حسب اليوم والأولوية (فاينل ← ميد ← امتحان ← كويز/مشروع ← واجب)، مع تمييز الأيام الثقيلة.
- **أوامر سريعة** تعمل حتى بدون ذكاء اصطناعي.

| الأمر | الوظيفة |
|---|---|
| `/today` | جدول اليوم |
| `/tomorrow` | جدول الغد |
| `/week` | بقية هذا الأسبوع |
| `/nextweek` | الأسبوع القادم |
| `/upcoming` | كل المهام في الـ 30 يوماً القادمة |
| `/exams` | الامتحانات القادمة |
| `/chatid` | رقم المحادثة (لضبط `ALLOWED_CHAT_IDS`) |
| `/help` | طريقة الاستخدام |

## 🚀 التشغيل

### 1. أنشئ البوت في تيليجرام
1. افتح [@BotFather](https://t.me/BotFather) واكتب `/newbot` واتبع الخطوات، وانسخ **التوكن**.
2. **مهم جداً:** اكتب لـ BotFather الأمر `/setprivacy` واختر البوت ثم **Disable**.
   بدون هذه الخطوة لن يرى البوت رسائل القروب العادية.
3. أضف البوت إلى قروب الدفعة.

### 2. احصل على مفتاح Claude API
من [platform.claude.com](https://platform.claude.com)، أنشئ مفتاح API.

### 3. شغّل البوت

```bash
git clone https://github.com/rad03i2/bot_steudent.git
cd bot_steudent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ثم ضع التوكن والمفتاح داخل .env
python -m study_bot
```

أو باستخدام Docker:

```bash
docker build -t study-bot .
docker run -d --name study-bot --env-file .env -v study-bot-data:/data --restart unless-stopped study-bot
```

### 4. (اختياري) اقفل البوت على قروبكم
اكتب `/chatid` داخل القروب، وضع الرقم في `ALLOWED_CHAT_IDS` داخل `.env` ثم أعد تشغيل البوت.
بعدها لن يستجيب البوت إلا لهذا القروب، ولأعضائه على الخاص.

## ⚙️ الإعدادات

كل الإعدادات في `.env` (انظر `.env.example`):

| المتغير | الافتراضي | الشرح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | توكن البوت (إلزامي) |
| `ANTHROPIC_API_KEY` | – | مفتاح Claude (بدونه يعمل البوت بالأوامر فقط) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | النموذج المستخدم |
| `CLAUDE_EFFORT` | `low` | عمق التفكير (low / medium / high) |
| `TIMEZONE` | `Asia/Baghdad` | المنطقة الزمنية |
| `WEEK_START` | `sunday` | أول يوم في الأسبوع |
| `MONTH_STYLE` | `levantine` | `levantine` = تشرين الثاني، `standard` = نوفمبر |
| `DB_PATH` | `data/study_bot.db` | مكان قاعدة البيانات |
| `ALLOWED_CHAT_IDS` | فارغ | القروبات المسموحة |
| `GROUP_PREFILTER` | `true` | في القروب، يرسل للذكاء الاصطناعي فقط الرسائل التي فيها كلمات دراسية |

### 💰 عن التكلفة
كل رسالة دراسية في القروب تُرسل إلى Claude مرة واحدة. الفلتر المسبق (`GROUP_PREFILTER`) يتجاهل السوالف العادية، فلا تُحتسب.
لتقليل التكلفة أكثر، يمكن استخدام `CLAUDE_MODEL=claude-haiku-5-5`، وهو أرخص بكثير، لكن فهمه للهجات أضعف قليلاً.

## 🧱 بنية المشروع

```
study_bot/
├── __main__.py      # نقطة التشغيل
├── config.py        # الإعدادات
├── arabic.py        # تطبيع النص العربي، أسماء الأيام والأشهر
├── dates.py         # تحويل "الخميس الجاي" إلى تاريخ (حتمي)
├── llm.py           # فهم الرسائل عبر Claude (Structured Outputs)
├── db.py            # التخزين في SQLite
├── formatting.py    # تنسيق البطاقات والجداول
├── service.py       # المنطق الأساسي (مستقل عن تيليجرام)
└── telegram_bot.py  # ربط المنطق بتيليجرام
tests/               # اختبارات (pytest)
```

تشغيل الاختبارات:

```bash
pip install -r requirements-dev.txt
pytest -q
```
